A one-line resignation letter for make.fun's "The Funniest One-Line Resignation Letter" bounty. The entry is a single line — a tech-support agent resigning mid-call and handing the job to the customer — written to `/output/entry.txt` by `main.py`. Nothing else, no trailing newline.

> My resignation, in one line: have you tried turning it off and on again? That was my job, and now it's yours.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

## How it works

`main.py` is self-contained and deterministic: no network, no secrets, no
arguments. It writes exactly the 109-character line above to
`/output/entry.txt` (UTF-8, no trailing newline), inside the 1–140 character
gate.
